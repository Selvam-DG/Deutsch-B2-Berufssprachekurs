
# Berufssprachkurs B2 – Learning Journal

This repository documents my progress during a **Berufssprachkurs Deutsch B2** at **Peters Bildungsgruppe in Rosenheim**.

The course runs from **15 June to 14 November** and concludes with the **telc Deutsch B2 examination on 14 November**.

## About

The purpose of this repository is to keep a structured record of the topics, exercises, vocabulary, grammar, and exam preparation covered during the course.

The journal is organized by course week and contains daily Markdown entries based on my own class notes.

The main goals of this repository are to:

* document my learning progress consistently
* strengthen my B2 grammar and vocabulary
