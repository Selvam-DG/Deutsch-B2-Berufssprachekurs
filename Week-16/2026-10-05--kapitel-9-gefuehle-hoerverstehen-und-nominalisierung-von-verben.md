## Grammatik

### Nominalisierung von Verben

**Kursbuch – Seite 139, Übungen 3a und 3b**

Bei der Nominalisierung wird ein Verb in ein Nomen umgewandelt. Diese Form wird besonders häufig in formellen und schriftlichen Texten verwendet.

**Wichtige Regeln:**

- Verben können auf verschiedene Arten nominalisiert werden.
- Häufig werden die Endungen **-ung, -er, -e, -nis** oder **-tion** verwendet.
- Auch der Infinitiv kann als Nomen verwendet werden. In diesem Fall ist der Artikel immer **das**.
- Manchmal verändert sich bei der Nominalisierung der Vokal im Wortstamm.

**Beispiele aus dem Kursbuch:**

| **Verb** | **Nominalisierung** |
| --- | --- |
| ausbauen | der Ausbau |
| auswählen | die Auswahl |
| fehlen | das Fehlen |
| fördern | die Förderung |
| optimieren | die Optimierung |
| mitarbeiten | die Mitarbeit |
| mitarbeiten | der Mitarbeiter / die Mitarbeiterin |
| folgen | die Folge |
| helfen | die Hilfe |
| erkennen | die Erkenntnis |
| ergeben | das Ergebnis |
| motivieren | die Motivation |

### Umformung der Akkusativergänzung

Bei der Nominalisierung kann sich auch die Satzstruktur verändern.

**Mit Artikelwort:**

- Die Firma führt einen Gesundheitstag ein.
- Die Einführung eines Gesundheitstages durch die Firma.

**Ohne Artikelwort:**

- Referenten vermitteln Strategien.
- Die Vermittlung von Strategien durch Referenten.

**Übungen:**

- **Übung 3a:** Nominalisierungen in einem Text über betriebliche Gesundheitsförderung erkennen.
- **Übung 3b:** Von Verben abgeleitete Nomen finden und die Regeln zur Nominalisierung ergänzen.
