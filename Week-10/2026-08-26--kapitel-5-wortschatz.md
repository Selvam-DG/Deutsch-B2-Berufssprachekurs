# Wortschatz – Lektion 5

## Auftakt

| **German word** | **German explanation or synonym** | **English translation** |
| --- | --- | --- |
| **die Messe** | eine große Veranstaltung, auf der Firmen ihre Produkte oder Dienstleistungen präsentieren | trade fair / exhibition |
| **das Messegelände** | das Gelände, auf dem eine Messe stattfindet | exhibition grounds / fairgrounds |
| **die Ausstellung** | eine Veranstaltung, bei der Produkte, Kunstwerke oder andere Dinge gezeigt werden | exhibition |
| **der Kongress** | eine größere Veranstaltung, bei der Fachleute zusammenkommen und über bestimmte Themen sprechen | congress / conference |
| **vertreten sein** | an einem Ort oder bei einer Veranstaltung präsent sein | to be represented / present |
| **der Aussteller / die Ausstellerin** | eine Person oder Firma, die auf einer Messe Produkte oder Dienstleistungen präsentiert | exhibitor |
| **der Ansprechpartner / die Ansprechpartnerin** | eine Person, an die man sich mit Fragen oder Problemen wenden kann | contact person |
| **der persönliche Kontakt mit + D.** | direkter Kontakt oder Austausch mit einer Person | personal contact with |
| **die Branche** | ein bestimmter Bereich der Wirtschaft, z. B. die IT- oder Baubranche | industry / sector |
| **der Schwerpunkt** | der wichtigste Bereich oder das zentrale Thema | focus / main emphasis |
| **spezialisiert auf + A.** | auf einem bestimmten Gebiet besonders erfahren oder qualifiziert | specialized in |
| **kompetent** | fachlich gut und qualifiziert; sachkundig | competent / knowledgeable |
| **der Kran** | eine große Maschine zum Heben und Bewegen schwerer Gegenstände | crane |
| **der Bagger** | eine Baumaschine zum Graben und Bewegen von Erde | excavator / digger |
| **die Schraube** | ein Metallteil mit Gewinde, mit dem man Dinge befestigt | screw |
| **das Give-away** | ein kleines kostenloses Werbegeschenk | promotional gift / freebie |
| **werben für + A.** | versuchen, Menschen für ein Produkt, eine Firma oder eine Idee zu interessieren | to advertise / promote |
