## Grammatik

### Passiv mit sein


* Wir lernten den Unterschied zwischen dem **Vorgangspassiv** und dem **Zustandspassiv**.
* Das Vorgangspassiv wird mit **werden + Partizip II** gebildet und beschreibt einen Vorgang oder eine Handlung.
* Das Zustandspassiv wird mit **sein + Partizip II** gebildet und beschreibt den Zustand oder das Ergebnis einer Handlung.

|   | Vorgangspassiv| Zustands­passiv|
|-----|---------|-------|
| | werden+ Partizip II | sein + Partizip II|
| Präsens| Das Boot **wird gebaut**. | Das Boot **ist gebaut**|
|Präteritum|  Das Boot **wurde gebaut** |Das Boot **war gebaut**|

**Beispiele:**

* Das Boot **wird gebaut**. → Vorgangspassiv
* Das Boot **ist gebaut**. → Zustandspassiv
* Das Boot **wurde gebaut**. → Vorgangspassiv im Präteritum
* Das Boot **war gebaut**. → Zustandspassiv im Präteritum
