## Kapitel 8 – Wortschatz

### Auftakt

| **German word** | **German explanation or synonym** | **English translation** |
| --- | --- | --- |
| **der Arbeitsunfall, ¨e** | ein Unfall, der bei der Arbeit oder auf dem Arbeitsweg passiert | workplace accident / occupational accident |
| **ausrutschen** | den Halt verlieren und auf einer glatten Fläche wegrutschen | to slip |
| **barrierefrei** | ohne Hindernisse; auch für Menschen mit Behinderung gut zugänglich | accessible / barrier-free |
| **der Rollstuhl, ¨e** | ein Stuhl mit Rädern für Menschen, die nicht oder nur schwer gehen können | wheelchair |
| **der Gefahrenhinweis, -e** | ein Hinweis, der vor einer Gefahr warnt | hazard warning / safety warning |
| **hinweisen auf + A.** *(weist hin, wies hin, hat hingewiesen)* | auf etwas aufmerksam machen | to point out / draw attention to |
| **videoüberwacht** | mit Kameras beobachtet und kontrolliert | under video surveillance / monitored by CCTV |
| **im Notfall** | wenn eine gefährliche oder dringende Situation eintritt | in an emergency |
| **der Brandmelder, -** | ein Gerät, das Rauch oder Feuer erkennt und Alarm auslöst | fire alarm / smoke detector |
| **der Notausgang, ¨e** | ein Ausgang, der bei Gefahr oder im Notfall benutzt wird | emergency exit |
| **der Rettungsweg, -e** | ein gekennzeichneter Weg, über den man sich bei Gefahr in Sicherheit bringen kann | escape route / evacuation route |
| **die Schutzkleidung** | Kleidung, die den Körper bei gefährlichen Arbeiten schützt | protective clothing |
| **die Warnweste, -n** | eine auffällige Weste, durch die man besser gesehen wird | high-visibility vest / safety vest |
| **der Schutzhelm, -e** | ein Helm, der den Kopf vor Verletzungen schützt | safety helmet / hard hat |
